# President Simulator Mobile LAN Preview

Temporary Android LAN preview wrapper for President Simulator mobile testing.

- Fullscreen landscape WebView
- Defaults to `http://192.168.1.10:4173/?mobile=1&apk=1`
- If the LAN address changes or the server cannot be reached, the app asks for a new address and remembers it.
- This repository does not contain the game source or production build.
